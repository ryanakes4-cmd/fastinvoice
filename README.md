# FastInvoice

Simple, fast invoice generator for freelancers and small businesses. Create professional PDF invoices in seconds.

## Features
- Create unlimited professional invoices
- Customizable line items, tax rates, and notes
- Clean, printable PDF output
- Mobile-friendly design
- No account required to get started

## Tech Stack
- Next.js + TypeScript
- Tailwind CSS
- Static export for fast performance commit changes
